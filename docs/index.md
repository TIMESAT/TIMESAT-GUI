# TIMESAT GUI User Manual

TIMESAT GUI is a desktop application for preparing, running, and reviewing TIMESAT time-series analyses. It is intended for scientific users working with vegetation index time series and related satellite-derived data.

## Main Workflow

The GUI is organized around four main steps:

1. **Inputs**: select input data, optional quality data, optional land cover data, and a processing region.
2. **Parameters**: configure TIMESAT fitting, pre-processing, weights, and season detection settings.
3. **Outputs**: choose the output folder, output naming, output time step, NoData value, and phenology outputs.
4. **Jobs**: run processing, monitor progress, stop a running job if needed, and review the output log.
