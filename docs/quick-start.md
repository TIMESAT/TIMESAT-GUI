## Before You Start

You need:

- A public TIMESAT GUI executable release.
- Public sample data. See [Sample Data](sample-data.md).
- A folder where TIMESAT GUI can write output files.

## Quick Workflow

1. Launch TIMESAT GUI.
2. Open the **Inputs** step.
3. Select a public sample input file.
4. If the sample uses image data, review the map preview.
5. Click **Load Data**.
6. Open the **Parameters** step.
7. Select one fitting method: **Double Logistic (DL)** or **Smoothing Spline (SP)**.
8. Review the time-series plot for a selected pixel or series.
9. Open the **Outputs** step.
10. Select an existing output folder.
11. Confirm output naming and selected phenology outputs.
12. Open the **Jobs** step.
13. Click **Run Subarea** for a small selected region, or **Run Full Data** for a small sample dataset.
14. Wait for the job to finish.
15. Review the output folder and the phenology table.
